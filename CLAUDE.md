# Project instructions

## Git authorship

All commits in this repository must be authored by the repository owner,
not by the assistant. Before making any commit, ensure:

```
git config user.name  "skymind-automation"
git config user.email "automationskymind@gmail.com"
```

Do not add `Co-Authored-By:` trailers or any other assistant attribution
lines to commit messages. Keep commit messages to a plain description of
the change.
